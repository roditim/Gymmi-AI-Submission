# דרישות ההגשה המעודכנות

הבהרת המרצה שהמשתמש מסר ב־4.11.2026 קודמת למסמך הפרויקט הישן: חובה אפליקציה שעובדת באינטרנט עם קישור ציבורי; CrewAI הוא המלצה בלבד; מודל ML מאומן אינו חובה. המרצה אישר להמשיך עם רעיון Gymmi. לא מפיצים כאן את הודעת ה־Slack או חומרי הקורס עצמם.

| רכיב | מצב בגרסת ההגשה |
|---|---|
| אפליקציה ציבורית פעילה | GitHub Pages, בנתיב /app/; תוצאת אימות נרשמת ב־verification/production-mvp-check.json |
| תוכנית אימונים בסיסית | הוספה ועריכה של אימונים לפי שבוע, עם תבנית דוגמה |
| סימון השלמה והתקדמות | הושלם, דילגתי, ביטול סימון, התקדמות והיסטוריה |
| שמירה | מצב אורח בדפדפן; חשבון מחובר שומר ב־Supabase עם RLS וגרסאות |
| הרשמה | הרשמה במייל וסיסמה ללא אימות כתובת, באישור מפורש עבור ה־MVP הלימודי |
| בדיקות ענן | תוצאות והגבלות ב־verification/supabase-cloud-check.json |
| קוד ציבורי | ריפו זה, עם היסטוריית ייבוא ו־PR אמיתי |
| ממשק RPG בסיסי | עיצוב מסע ומשימות בלבד; ללא XP, דמויות או רמות |
| מצגת קצרה | מצגת באנגלית ב־docs/index.html; הערות בעברית ב־private presentation notes |
| הכנה להצגה | מדריך חזרה והדגמה ב־private presentation notes |
| AI פעיל | עוזר שיבוץ עם OpenAI מאחורי פונקציית שרת, בדיקת פלט ואישור משתמש |
| CrewAI ו־ML | ניסויי מחקר אופציונליים, אינם תלות של האפליקציה הציבורית |

הודעת ההגשה המקורית ציינה Slack, קישור GitHub ומצגת קצרה עד 10.11 ללא שנה מפורשת. כאן לא נשלחה הודעה ולא הוגשה העבודה. חשבונות ו־Supabase נוספו לבקשת המשתמש; הבהרת המרצה לא חייבה אותם. לא נוספו שרת בתשלום, RPG או ML למוצר. אין להציג סוכני AI כסטודנטים שותפים. הרשמה ללא אימות מייל אושרה במפורש ב־4.11.2026. בדיקת הרשמה אמיתית מתועדת ב־verification/signup-check.json. אין לטעון לאימות בעלות על הכתובת או לשחזור סיסמה.

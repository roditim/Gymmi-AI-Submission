# הערות להצגת Gymmi — כ־6 דקות ועוד הדגמה

פתחו את index.html בדפדפן. גללו או השתמשו ב־Page Down; F11 למסך מלא. אפשר גם הדפסה לרוחב. הקובץ עובד ללא התקנה וללא חיבור לספק LLM.

## 1. Gymmi AI

כ-6 דקות ואחריהן הדגמה. המטרה העיקרית היא להראות מסירה בטוחה בין צוות ניתוח לצוות מדע נתונים. נעזרתי בעוזר קוד; עליי להבין ולהסביר את המימוש.

## 2. הנתונים והיעד

היוצרים: Simon Condliffe, Ebru Isgin, Matt Saboe. הוספנו מפתח שורה והמרנו week2 ליעד בינארי. הרשומות אינן ספירת אנשים: המקור מציין 245 משתתפים והפער אינו מוסבר. זו משימה שבועית, לא תחזית להזמנה לשיעור. מקור ורישיון: https://zenodo.org/records/18866086 ; https://zenodo.org/api/records/18866086 ; DATA_ATTRIBUTION.md.

## 3. שני צוותים, שלושה סוכנים בכל צוות

פתחו gymmi/crews.py. לכל סוכן Agent, Task וכלי מוגדר. Analyst מפיק clean_data.csv, eda_report.html, insights.md, dataset_contract.json. Scientist מפיק features.csv, model.joblib, evaluation_report.md, model_card.md. אלה שמונת התוצרים, וכל אחד שמור ב-artifacts/weekly-live. Scientist אינו מקבל נתיב ל-raw CSV.

## 4. חוזה הנתונים ושערי האימות

הקבצים הם boundary.py, feature_gate.py ו-artifact_status.py. checksum מזהה שינוי בבייטים; בדיקות תוכן בודקות את הכללים. אף בדיקה אינה מוכיחה לבדה משמעות אמיתית של עמודות. גרסת חוזה 3.0 ואישור 2 חוסמות ריצות מהמקור הישן. הדגמת יחידות משנה עותק בלבד.

## 5. הפיצול ובחירת המודל

seed=42. הקבוצה היא ארבע ספירות היסטוריות, לא אדם. חיוביים: 109/182 באימון, 38/64 באימות, 35/143 בבדיקה. לכן זו בדיקת דפוסים חדשים עם שכיחות שונה, לא מבחן כרונולוגי או הפרדה בין אנשים. לא חיפשנו seed שמשפר את ה-test. scaling אינו צמצום ממדים: ארבעה קלטים נשארים ארבעה.

## 6. השוואת המודלים

מקור הטבלה: artifacts/weekly-live/metrics.json. AP מודד דירוג; F1 משלב precision ו-recall בסף שנבחר. Dummy משתמש בשכיחות האימון. ל-RF מדדי דירוג מעט גבוהים יותר ב-test, אך הבחירה נעשתה מראש לפי validation. אין הוכחת כיול או היעדרות overfitting.

## 7. הדגמת הצלחה וכשל

הפעלת Streamlit והדגמה לפי DEMO_HE.md. בחרו weekly-live כדי לראות סקירות חיות. להרצת כשל השתמשו בשם תיקייה חדש ובפקודה python run.py --handoff artifacts/weekly-live --break units --output runs/demo-units-new. מצופה exit code 2 וללא מודל. שני ניסיונות live קודמים נכשלו בשער הסקירה; הם לא נספרים כריצות מוצלחות. GitHub Actions אינו פעיל עקב הרשאת workflow חסרה; 112 הבדיקות כאן נמדדו מקומית בעותק הנקי.

## 8. מגבלות ומה למדתי

סדר השבועות הוא הנחה לפי השמות. הסתייגויות נוספות מסקירות הסוכנים נשמרות ב-docs/SEMANTIC_REVIEW.md. מקור הנתונים ברישיון CC BY 4.0 אינו מתיר להפיץ חומרי קורס. הריפו הציבורי מתחיל בייצוא מסומן, בלי להמציא שותפים או היסטוריה. אין אישור מרצה או ביקורת אנושית עצמאית מתועדים.

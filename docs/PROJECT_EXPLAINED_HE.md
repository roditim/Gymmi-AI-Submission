# Gymmi בפשטות

המוצר הפעיל הוא תוכנית ומעקב למתאמן. המשתמש מוסיף אימונים לשבוע, כותב את הפרטים, מסמן השלמה או דילוג ורואה התקדמות. תוכנית הדוגמה היא תבנית ארגון שאפשר לערוך, ללא יצירת המלצות ב־AI.

שלושת הקבצים הפעילים הם docs/app/index.html, style.css ו־app.js. HTML מגדיר את המסך, CSS את העיצוב ו־JavaScript את הפעולות. מערך workouts מכיל אובייקט לכל אימון. כל אובייקט כולל מזהה, תאריך, שם, משך, תיאור וסטטוס. שמירה היא JSON בתוך localStorage.

כשלוחצים על השלמה, הקוד מעדכן את האובייקט, מנסה לשמור בדפדפן ורק אז מעדכן את התצוגה. מספר האימונים שהושלמו חלקי מספר האימונים בשבוע הוא ההתקדמות. אימון שלא סומן נשאר לא ידוע. אין סימון השלמה לאימון עתידי. שינוי חוזר לא מוסיף אימון חדש.

בגיבוי מייצאים JSON. בייבוא בודקים מבנה, תאריכים, מזהים וסטטוסים, ומבקשים אישור לפני החלפת היומן. אין חשבון משתמש, אין מידע משותף בין דפדפנים ואין סנכרון אוטומטי בין מכשירים.

האפליקציה מפורסמת באינטרנט דרך GitHub Pages. לפי הבהרת המרצה מ־4.11.2026 זו דרישת החובה. CrewAI ומודל מאומן הם אפשרות, לא חובה. ניסויי שני הצוותים והמודלים נשמרו כמעבדת מחקר; הם אינם מפעילים את המוצר הציבורי. לא מציגים מודל ביקורים כחיזוי השלמת אימון.

היעזרות בעוזר קוד מצוינת בגלוי. לתרגול: להסביר יצירת אימון, שמירה, סימון השלמה, חישוב התקדמות, גיבוי ופריסה. לא נדרש להסביר חבילת ML כדי להציג את המוצר הפעיל.

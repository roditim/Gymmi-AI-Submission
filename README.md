# Gymmi — תוכנית אימונים והתקדמות

[פתח את האפליקציה הציבורית](https://roditim.github.io/Gymmi-AI-Submission/app/) · [מצגת קצרה](https://roditim.github.io/Gymmi-AI-Submission/) · [איך להציג למרצה](docs/DEMO_HE.md)

Gymmi הוא MVP למתאמן שרוצה לארגן אימונים בשבוע ולראות מה השלים. לפי הבהרת המרצה שהועברה ב־4.11.2026, פריסה ל־Production עם קישור ציבורי היא חובה; CrewAI הוא המלצה ומודל ML מאומן אינו חובה. ההבהרה הזו מנחה את גרסת ההגשה.

## מה עושים באפליקציה

1. בוחרים שבוע ומוסיפים אימון: שם, תאריך, משך מתוכנן ותרגילים מתוך התוכנית האישית.
2. אפשר להתחיל משלושה אימונים לדוגמה ולערוך אותם.
3. אחרי אימון מסמנים הושלם או דילגתי. אפשר לבטל סימון ולתקן פרטים.
4. רואים כמה אימונים הושלמו מתוך התוכנית השבועית ואת היסטוריית האימונים.
5. מורידים גיבוי JSON ומשחזרים אותו במכשיר אחר.

הנתונים נשמרים ב־localStorage בדפדפן של כל מבקר. אין חשבונות, שמירה משותפת בשרת או סנכרון אוטומטי. מחיקת נתוני הדפדפן מוחקת את היומן המקומי; גיבוי מאפשר להעביר אותו. תוכנית הדוגמה היא תבנית לארגון, ולא תוכנית שנבנתה באמצעות AI או הותאמה רפואית.

## קוד שאפשר להסביר

| קובץ | אחריות |
|---|---|
| docs/app/index.html | מסכי האפליקציה והטפסים |
| docs/app/style.css | עיצוב והתאמה לטלפון |
| docs/app/app.js | שמירה, אימות נתונים, עריכה, סימון השלמה וחישוב התקדמות |
| tests/browser_mvp.cjs | בדיקות משתמש בדפדפן |

זו אפליקציה סטטית עם HTML, CSS ו־JavaScript פשוטים, ללא framework או שלב build. GitHub Pages מגיש את הקבצים ב־HTTPS. הגרסה הציבורית אינה מפעילה חיזוי או סוכני AI ואינה זקוקה למפתח API.

## הרצה מקומית

אפשר לפתוח docs/app/index.html, אך מומלץ שרת מקומי כדי לקבל סביבת דפדפן עקבית:

```powershell
python -m http.server 8520 --directory docs/app
```

פותחים http://localhost:8520. לא צריך להתקין את חבילות מעבדת ה־ML כדי להריץ את המוצר.

## בדיקות

נבדקו שמירה אחרי רענון, שינוי וביטול השלמה, חסימת סימון עתידי, מניעת תוכנית דוגמה כפולה, ייצוא ושחזור גיבוי, דחיית קובץ שגוי בלי החלפת מידע, הפרדה בין דפדפנים, שמירה שנחסמה, הצגת טקסט משתמש והתאמה לטלפון. ראו verification/production-mvp-check.json עבור תוצאות שנמדדו בפועל. בדיקות האפליקציה הן בדיקות דפדפן; אין לבלבל בינן לבין בדיקות מעבדת הנתונים הישנה.

לבדיקות דפדפן אופציונליות בסביבת פיתוח:

```powershell
npm install --no-save playwright
npx playwright install chromium
node tests/browser_mvp.cjs http://localhost:8520/
```

לא נדרשים npm או Python כדי להשתמש באפליקציה הציבורית. בדיקות היישום אינן רצות אוטומטית ב־GitHub Actions; לחיבור הפרסום אין הרשאת workflow.

## עבודת המחקר הקודמת

קוד Python, CrewAI, נתוני Zenodo והתוצרים ב־artifacts/weekly-* נשמרים כמעבדת מחקר היסטורית. הם חוזים ביקור שבועי, ואינם משמשים את המוצר הציבורי או מוצגים כחיזוי השלמת אימון. 112 בדיקות שדווחו בפיתוח המקורי מתייחסות לאותה מעבדה. ניסוי השלמה סינתטי נשמר בנפרד ואינו רכיב חובה בהגשה או ראיה לביצועים על אנשים אמיתיים.

רישיון נתוני המחקר ההיסטוריים ב־DATA_ATTRIBUTION.md. המוצר הפעיל אינו מוריד דאטה ואינו שולח את היומן לספק AI.

## Git והגשה

הריפו הציבורי התחיל בייצוא מסומן של עבודה פרטית מוקדמת. ההיסטוריה אינה משחזרת תאריכים או שותפים. משתמשים בענפים וב־PR אמיתי, ומציינים בכנות שנעזרנו בעוזר קוד. חומרי הקורס, ההיסטוריה הפרטית והמפתחות אינם חלק מההגשה. אין כאן טענה לביקורת אנושית עצמאית, לציון מובטח או לכך שכבר נשלחה ההגשה.
